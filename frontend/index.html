About

Metaplasia

A native Windows 11 shell customization engine with a Tauri control center.

ApplicationMetaplasia

Taskbar, Start menu, and File Explorer customization from one local control surface.

InterfaceTauri v2 + WebView2

Bundled static assets, native window management, and hardware-accelerated rendering.

TransportPer-user named pipe

Versioned binary IPC restricted to your current Windows user and session.

Portable channel

Updates

Signed full-package updates from GitHub Releases. No installer or background service.

Loading update status…

The updater only contacts the Metaplasia GitHub Releases channel.

Portable update

Install the verified update?

The complete portable binary set will be replaced. Your settings stay in %LOCALAPPDATA%\Metaplasia.

Metaplasia will close and Explorer and Start will briefly restart so the injected DLL can be replaced safely.
